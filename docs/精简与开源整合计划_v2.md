# 语料清洗工具精简与开源整合计划 v2

## Summary

基于用户确认的 5 个痛点（同脚本乱码、表格过滤双向误判、分类器不准、近重复漏检、编码/双语/纯图片边界情况），以及 Profile 预设架构共识，重新设计修改计划。核心变更：公开 API 从 12 参数精简到 5 个，引入 fast-langdetect + ftfy + trafilatura（可选），8 项功能增强，删除 8 个一次性脚本。

## Key Changes

**Profile 预设系统**
- 公开 CLI：`--input`, `--output`, `--profile`, `--dry-run`, `--lang`（5 个）
- quick：基础清洗 + ftfy + fast-langdetect（~2min）
- standard（默认）：+ KL 散度 + HTML 噪音 + 评分分类器 + 增强白名单（~2.5min）
- thorough：+ 逐行语言检测 + trafilatura + 低阈值去重 + clean-light OCR（~8min）

**开源依赖**
- 引入：fast-langdetect（替换 langdetect）、ftfy（编码修复）、trafilatura（thorough 专用）
- 移除：langdetect
- 不引入：clean-text、text-dedup、DataTrove、Presidio、spaCy、Unstructured

**8 项功能增强**
1. 同脚本乱码检测：字符频率 KL 散度（ocr_handler.py + lang_profiles/）
2. 表格过滤双向修正：is_html_noisy() + is_image_only() + trafilatura 救援
3. 评分式分类器：权重评分 + 语言感知关键词
4. 去重阈值参数化：config.dedup_threshold 替换硬编码 0.95
5. 纯图片文档检测：路由到 _image_only/
6. 双语白名单增强：行内代码 + LaTeX + 技术术语
7. ftfy 编码修复：read_file_auto() 后追加 fix_text()
8. fast-langdetect 替换：速度 100x

**轻量精简**
- 删除 8 个一次性辅助脚本
- 6 处硬编码转可配置

**Skill 接口重设计**
- LLM 可见参数从 12 减到 5
- Step 2 简化为只问 profile

## Test Plan

- `python -m pytest corpus_cleaner/tests/` 全部通过
- 不加 `--profile` 时行为与当前完全一致（向后兼容）
- `--profile quick/standard/thorough` 各档行为符合预设定义
- `--lang AR` 强制语言时 scanner 不调用语言检测
- ftfy 修复后无 mojibake 残留（抽检 50 文件）
- fast-langdetect 准确率 >= langdetect
- 纯图片文档路由到 `_image_only/`
- HTML 噪音文件正确识别
- SKILL.md 中 LLM 可见参数仅 5 个

## Assumptions

- fast-langdetect 首次调用需下载 fastText 模型（~1MB），预下载到项目目录确保离线可用
- ftfy 误修率极低（<0.01%），且修复幂等
- trafilatura 仅对含 HTML 的文件有效，对纯 markdown 无副作用
- 3K 文件规模不需要分布式框架（DataTrove）或重型去重库（text-dedup）
- 当前无 PII 脱敏需求，不引入 Presidio
